# NetSec Matrix

I made NetSec Matrix to help me study cybersecurity. I wanted one place to look up the codes and terms I kept seeing in my networking and ethical hacking labs.

## What it covers

There are 41 quick references. Each one explains what the code or term means and why it matters for security. A few examples are Port 22 for SSH, 404 Not Found, DNS records, and Linux exit codes.

## How I built it

I built this project with help from Google AI Studio and synced it to GitHub.
